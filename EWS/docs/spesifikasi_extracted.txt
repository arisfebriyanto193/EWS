Logika Operasi EWS
1. Perangkat membaca sensor secara berkala dan menyimpan hasil pengukuran dengan cap waktu.
2. Data dikirim melalui GSM dan 4G ke server menggunakan protokol HTTPS atau MQTT yang dilindungi
autentikasi.
3. Status aman, siaga, bahaya, offline, baterai lemah, dan gangguan sensor ditentukan berdasarkan
aturan yang disetujui saat commissioning.
4. Sirine dan strobo aktif secara lokal ketika kondisi bahaya memenuhi syarat konfirmasi pembacaan.
5. Telegram dan dashboard menerima kejadian alarm, lokasi, waktu, nilai sensor, dan status perangkat.
6. Data yang gagal terkirim disimpan pada MicroSD dan dikirim ulang ketika koneksi tersedia.

Pengujian Penerimaan EWS
 Pembacaan seluruh sensor tampil pada perangkat lokal dan dashboard.
 Empat perangkat dapat mengirim data melalui kartu SIM pada lokasi pemasangan.
 Sirine dan strobo dapat diuji dari tombol lokal dan perintah operator yang diizinkan.
 Alarm lokal tetap bekerja saat koneksi seluler diputus.
 Notifikasi Telegram diterima ketika status siaga, bahaya, offline, baterai lemah, atau sensor gagal.
 Box, gland, konektor, rangka, kabel, dan fondasi telah diperiksa sebelum serah terima.
 Data tetap tercatat selama gangguan jaringan dan tersinkron setelah jaringan kembali.

Bagian 4 Web Monitoring dan Telegram
Sistem digital menerima data dari empat titik EWS melalui jaringan GSM dan 4G, menyimpan data pada
server, menampilkan kondisi melalui dashboard web, serta mengirim notifikasi Telegram kepada operator
atau grup yang ditentukan. Dashboard dapat dibuka melalui komputer maupun telepon seluler.

Arsitektur Sistem
1. ESP32 membaca sensor dan menentukan status lokal berdasarkan konfigurasi perangkat.
2. Modem GSM dan 4G mengirim data melalui HTTPS atau MQTT menggunakan identitas perangkat
yang unik.
3. Server memvalidasi, menyimpan, dan mengolah data dari keempat titik.
4. Dashboard web menampilkan status terkini, grafik, peta, histori alarm, serta kesehatan perangkat.
5. Telegram Bot mengirim pemberitahuan ketika terjadi perubahan status atau gangguan perangkat.

Catatan Keselamatan
EWS berfungsi sebagai sarana pemantauan dan peringatan komunitas. Keputusan evakuasi tetap
mengikuti prosedur pemerintah desa, BPBD, dan pihak berwenang. Nilai ambang tidak ditetapkan hanya
dari spesifikasi sensor; penetapannya memerlukan survei lokasi, data dasar, evaluasi kondisi tanah, dan uji
lapangan.
